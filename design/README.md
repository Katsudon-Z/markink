# Markdownエディタ UI定義

Penpotの現在の編集画面をMCP経由で書き出したスナップショットです。

- `MarkInk メイン.penpot`: MarkInkのネイティブPenpotデザインファイル。

- `markdown-editor.svg`: 画面のSVG書き出し。表示・取り込み用。
- `markdown-editor.json`: レイヤー階層、絶対座標、サイズ、文字、色、罫線などの定義。
- `markdown-editor-icons.svg`: 初期版向けのアイコンツールバー版。
- `markdown-editor-icons.json`: アイコン版のレイヤー定義。非表示状態、パス、操作名などのメタデータも含む。

書式ボタンのコンパクト化、右側の目次、下部ステータスバーへの保存状態移動を反映しています。
日本語ラベル版には見出し1〜3ボタンと通常文へ戻す「本文」ボタンを反映し、アイコン版を別途書き出しています。

JSONは独自のスナップショット形式で、Penpotへ直接インポートする形式ではありません。SVG/JSONはネイティブファイルの完全なバックアップではありません。

使用フォントはM PLUS 2です。SVGの表示環境によってフォントが置換される場合があります。
