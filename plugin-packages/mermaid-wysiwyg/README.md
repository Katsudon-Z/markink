# Mermaid ビジュアルエディタ

markink-mermaid-editorとは別のプラグインです。ZIPにMermaid、ビジュアル編集ライブラリ、既存のOffice変換モジュールを同梱し、通信なしで動作します。

## 導入

対応する最新版markink.exeで、markink-mermaid-wysiwyg-1.0.0.zipを導入して有効化します。メニューの「Mermaid図をビジュアル作成」、またはMermaidコードブロックを選択して「Mermaid図をビジュアル編集」を選びます。

本体は同じ言語の描画プラグインを複数登録できます。最後に有効化したものが文書を描画し、無効化すると以前の描画プラグインに戻ります。既存の記法エディタも併用できます。WYSIWYG側の文書描画では右クリック「図をビジュアル編集」を利用できます。別の描画プラグインが優先されている場合もメニューからビジュアル編集できます。

## 図上編集（フローチャート）

- ノードと接続の選択、文字のダブルクリック編集、選択した要素のプロパティ編集。
- 14形状のノード追加・形状変更・複製・削除、塗り・枠・文字色の変更。
- 「接続」モードまたはAltキーを押してノード間をドラッグし、接続を追加。右側の接続元・接続先でも追加できます。
- 接続のラベル、実線・点線・太線、矢印・×・丸・矢印なし、方向反転・削除。
- 図の向き、パン・ズーム、記法欄との双方向同期、共通のUndo/Redo。
- 記法欄は表示/非表示でき、図との境界をドラッグ・左右キーで調整できます。

配置はMermaidの自動レイアウトです。ノードの自由な座標移動を保存する機能ではありません。サブグラフやコメントなど、編集対象外の記法を全体書き換えで消さない方式です。OSSが要素を照合できない構文は図上編集できない場合があり、記法欄から編集できます。シーケンス図・状態図などはこの版では表示と記法編集で扱います。

## 保存とコピー

文書には通常のmermaidコードブロックで反映します。「文書に反映」後も閉じず、同じブロックを続けて更新できます。別の操作で文書が更新された場合は版の不一致を検出して反映を拒否します。

文書の図およびエディタ内の図を右クリックし、Mermaid記法・PowerPoint図・PNGを選びます。Office変換は既存プラグインと同じモジュールです。ノードの接続点・色・ラベル・線種の対応も共通です。PNG/Officeコピーは選択枠やズーム操作を取り除いたMermaidのSVGから生成します。PowerPoint自体の起動は不要です。コピー成功は状態欄に表示し、図の中には表示しません。

記法は100,000文字まで、編集画面HTMLとコピー要求は16 MiBまでです。PNGは20,000,000画素までです。PowerPoint図への変換対象と未対応要素は既存プラグインと同じです。

## 開発

node scripts/build-mermaid-wysiwyg-plugin.mjs

ビルド時にmermaid-editorの共通ランタイムとOffice変換を取り込み、独立したindex.jsと資源を生成します。実行時に他のプラグインを必要としません。manifest.jsonのfileHashesに列挙された資源とmanifestをZIP直下へ格納して配布します。本体にMermaid固有コードは追加しません。
