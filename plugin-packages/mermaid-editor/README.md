# Mermaid エディタ

拡張メニューから「Mermaid図を作成」を選び、左側にMermaid記法を入力します。右側にプレビューが表示され、描画に成功すると「文書に反映」を押せます。文書には `mermaid` 言語のコードフェンスとして原文を保存し、編集画面では図として表示します。図を選択して「Mermaid記法を編集」で再編集できます。プラグインを無効にするとコードブロック表示に戻ります。

描画ライブラリはZIPに同梱しています。プラグインの動作時に外部サービスへの接続は不要です。以前のSVG画像形式で作成したMermaid図も、選択して編集するとコードフェンスへ変換できます。

文書内の図をクリックすると図を選択できます。図の上下の余白をクリックするか、図を選択して上下矢印キーを押すと、前後の段落にカーソルを置けます。図を右クリックすると、Mermaid記法、PNG、PowerPoint図を選んでコピーできます。コピーが失敗した場合だけ図の下にエラーを表示します。PowerPoint図はフローチャートに対応します。本体が図形・線・文字をOffice用形式でクリップボードへ書き込むため、コピー時にPowerPointの起動は不要です。PowerPointへの貼り付けと個別編集は実機未検証です。PowerPoint図のコピーには `office.copy`、クリップボードへの書き込みには `clipboard.write` 権限が必要です。

同梱するMermaidは11.17.2です。関連するライブラリとライセンスはTHIRD_PARTY_NOTICES.txtに記載しています。
