# Mermaid エディタ

`stateDiagram` / `stateDiagram-v2` のPowerPoint図コピーにも対応しています。標準のdagre-wrapperレンダラーのSVGとMermaid解析DBを使い、状態、開始・終了記号、choice、fork/join、複合状態、並行状態、注記、説明欄、遷移ラベルを編集可能なOffice要素に変換します。遷移はノード上の実際の位置へ接続し、接続点はサイズ変更に追従します。分岐・バーの輪郭は直線で出力し、塗りと線を二重に出力しません。複合状態の背景・見出し、説明欄の文字・区切り線は別要素なので、まとめて移動する場合はPowerPointでグループ化してください。例は `state-example.md` にあります。状態図の解析は `state-office-drawing.js` に分離し、輪郭と接続点の処理はフローチャートと共用しています。旧dagre-d3レンダラーを明示指定した図、画像・HTMLラベルはPNGでコピーしてください。

シーケンス図のparticipant文字色は、SVGのtspanに設定された実際の文字色を使います。

`sequenceDiagram` のPowerPoint図コピーに対応しています。参加者・actor・ライフライン・活性区間・メッセージ・ノート・loop/alt/opt/par/critical/breakの枠・背景色・自動番号をSVGの配置から変換します。メッセージはライフラインまたは活性区間の実際の線端点に接続し、実線・点線、三角矢印・非同期矢印・両方向・×を保持します。文字サイズ・文字色・複数行・半透明の背景も引き継ぎます。

自己呼び出しは、折り返し形状を保持した1つの開いた自由形状として出力します。自己呼び出しの線はOfficeのコネクタではなく、ライフライン移動時の自動追従には対応していません。参加者の箱とライフラインも別の編集要素です。通常メッセージはライフライン移動に追従します。片側だけの半矢印はOfficeの通常矢印に近似します。画像・数式を含む図はPNGでコピーしてください。例は `sequence-example.md` にあります。シーケンス変換は `sequence-office-drawing.js` に分離しています。

PowerPoint図では、丸括弧付きの図形をPowerPoint標準の角丸四角形、サブルーチンを標準の定義済み処理図形、データベースを標準の円柱図形に変換します。平行四辺形と台形はSVGの頂点を使った直線輪郭にします。角丸四角形と非対称形は重複する上側の図形を出力しません。

PowerPoint図への変換では、SVGに文字がない図形のラベルをMermaid記法の解析結果から補い、長い文字は図形内に収まるよう調整します。

PowerPoint図への変換では文字枠の余白をなくし、線のラベル枠を広げて文字がはみ出しにくい寸法にします。

PowerPoint図の×付き矢印は、×の2本の線を図形上の専用接続点につなぎ、図形の移動に追従させます。

拡張メニューから「Mermaid図を作成」を選び、左側にMermaid記法を入力します。右側にプレビューが表示され、描画に成功すると「文書に反映」を押せます。文書には `mermaid` 言語のコードフェンスとして原文を保存し、編集画面では図として表示します。図を選択して「Mermaid記法を編集」で再編集できます。プラグインを無効にするとコードブロック表示に戻ります。

描画ライブラリはZIPに同梱しています。プラグインの動作時に外部サービスへの接続は不要です。以前のSVG画像形式で作成したMermaid図も、選択して編集するとコードフェンスへ変換できます。

文書内の図をクリックすると図を選択できます。図の上下の余白をクリックするか、図を選択して上下矢印キーを押すと、前後の段落にカーソルを置けます。図を右クリックすると、Mermaid記法、PNG、PowerPoint図を選んでコピーできます。コピーが失敗した場合だけ図の下にエラーを表示します。PowerPoint図は `graph` / `flowchart` / `sequenceDiagram` / `stateDiagram` / `stateDiagram-v2` 記法に対応し、描画済みSVGからノード形状、サブグラフ、色、線種、矢印、文字をOffice図形へ変換します。Mermaid記法をMermaid本体で解析し、ノード間の接続情報をOfficeコネクタへ渡します。標準図形の接続点ではSVGの線端点と合わない場合、ノードをカスタム図形に変え、輪郭上の線端点を個別の接続点にし、編集用に標準位置、各辺の中点、頂点の接続点も追加します。四角形とひし形の辺は直線で出力します。本体がOffice用形式でクリップボードへ書き込むため、コピー時にPowerPointの起動は不要です。画像ノードのPowerPoint形式コピーとクリック動作の移植には対応していません。PowerPoint図のコピーには `office.copy`、クリップボードへの書き込みには `clipboard.write` 権限が必要です。

PowerPoint図形データへの変換処理は `office-drawing.js` に分けて同梱しています。`-->` は実線矢印、`-.->` は点線矢印、`--x` は×付き矢印、`==>` は太線矢印として扱います。同梱するMermaidは11.17.2です。関連するライブラリとライセンスはTHIRD_PARTY_NOTICES.txtに記載しています。

図を右クリックして「図を編集」を選ぶとMermaidエディタを開きます。状態図の開始点は円周上の実際の線端点へ接続します。終了記号は外周と中央の点を1つのbullseye図形にまとめ、移動・サイズ変更で分離しません。この形式にはv1.3.1対応の本体exeが必要です。

「文書に反映」はエディタを閉じずに文書を更新します。続けて修正し、同じ図へ何度でも反映できます。成功・失敗を編集画面内に表示します。反映後に閉じても、反映した内容は文書に残ります。別の操作や共同編集で文書の版が変わった場合は誤上書きを避けて反映を止め、図を開き直すよう案内します。この機能にはv1.3.2対応の本体exeが必要です。

pieのPowerPoint図コピーに対応しています。SVGから扇形の配置・色・塗り透明度、割合、タイトル、凡例、showDataの値を引き継ぎます。扇形の円弧は自由形状の直線輪郭で近似しますが、径の直線と境界の頂点は保持します。100%の単一セクションは標準の楕円図形、凡例の色見本は標準四角形です。donutHoleのある扇形も保持します。全周ドーナツは穴を持つ自由形状と外周/内周の輪郭を別要素にするので、まとめて動かす場合はグループ化してください。パイチャートは編集可能なOffice図形としてコピーし、PowerPointのチャートデータ編集機能には変換しません。変換はpie-office-drawing.jsに分離しています。例はpie-example.mdにあります。本体はv1.3.2対応exeを引き続き使用できます。

architecture-betaのPowerPoint図コピーに対応しています。標準のcloud/database/disk/internet/serverアイコン、service、group、入れ子のグループ枠、junction、方向指定の接続、片方向/両方向矢印、グループ端への接続、ラベルをSVGと解析データからOffice要素へ変換します。サービスのアイコン部品とラベルはOfficeグループにまとめ、グループ内の背景図形へコネクタを接続します。グループを移動すると部品と接続点も移動し、解除すると部品ごとに編集できます。junctionはSVG同様に見えない接続図形です。アーキテクチャの囲み枠、囲み枠の見出し/アイコン、内側のサービスは別要素なので、一括移動する場合はPowerPointでまとめてグループ化してください。線ラベルの回転とアイコン内SVGの倍率に応じた線幅を保持します。曲線は自由形状の直線輪郭で近似し、曲がる接続線は既存のOffice曲線コネクタへ変換するためSVGと曲がり方が異なる場合があります。画像・外部参照アイコンと複数輪郭の塗りを持つカスタムアイコンはPNGでコピーしてください。変換はarchitecture-office-drawing.js、例はarchitecture-example.mdです。グループ/回転APIを追加したv1.5.0対応exeとZIPを両方使用してください。
大きい図の表示領域は最大65536pxまで自動拡張します。それより高い図も内部スクロールで下まで表示できます。図とエラー本文の実際の高さを監視し、ウィンドウ幅変更時も描画領域の高さを更新します。v1.5.1対応exeとZIPを使用してください。

入力欄とプレビューの境界をドラッグすると幅を変更できます。境界にフォーカスして左右キーでも調整できます。エディタの図を右クリックすると、Mermaid記法・PowerPoint図・PNGを文書側と同じ処理でコピーできます。最新プレビューの描画が完了してからコピーしてください。この機能にはv1.6.0 ZIPと対応する最新版exeの両方が必要です。
