# Office カスタム曲線コネクタ試作

対応する最新版exeとこのZIPを導入し、有効化して「Officeカスタム曲線を試す」を開きます。

弧、S字、U字、複数区間の4例を用意しています。カスタム曲線（接続あり/なし）、標準曲線（接続あり）を個別にコピーしてPowerPointへ貼り付けます。表示しているSVGはカスタム曲線の目標形状です。標準曲線は比較用で、表示形状と異なります。

本体の汎用Office APIにbezierSegmentsを追加する試作です。各区間は [制御点1, 制御点2, 終点]、開始点はpoints[0]、最後の終点はpointsの末尾と一致させます。最大32区間。接続先ID/接続点と線種/矢印の従来指定を維持します。カスタム形状は1つのa:cxnSpの中にa:custGeom/cubicBezToで記述し、開いたパスにします。全制御点を含む座標範囲を100000単位へ正規化し、拡大縮小に対応します。

今回はMermaid変換へまだ組み込みません。まず既知の制御点でOfficeの挙動を切り分けます。貼り付け直後の形状、コネクタとしての選択、ノード移動時の両端追従と経路、全体拡大縮小、保存・再読込を確認してください。接続を付けると形が変わる場合、接続なしとの比較でPowerPointの再計算の影響を確認できます。

確認結果が良ければ、次にMermaid SVGのC/Qなどを制御点へ変換して共通Officeコピーへ組み込みます。PowerPoint本体の起動や制御はコピー処理に不要です。

## 試作結果（2026-10-03）
実機ではカスタム曲線は全例ペースト不可。MicrosoftのOffice実装仕様MS-OI29500 2.1.1603では、コネクタcxnSpはpreset geometryのみ対応しcustom geometryを許可しないと明記されています。この試作方式は製品へ採用しません。規格のスキーマで記述できることとOfficeで利用できることは異なります。既存Mermaidの標準コネクタコピーにはこの試作を組み込んでいません。
