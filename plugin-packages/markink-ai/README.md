# markink AI HTTP

ZIPをmarkinkに導入して有効化します。プラグイン管理画面でAPIキーを設定し、
プラグイン管理画面からURL、モデル名、送信上限、タイムアウト、APIキー利用を指定してください。
既定のURLはOpenAI互換のchat/completionsです。認証不要のローカルサーバも選べます。
文書内容は選択したサーバへ送信されます。通信先はmanifest.jsonで列挙したoriginのみです。

拡張メニュー、右クリックメニュー、ショートカットから要約、続き、質問、編集代行を使えます。
Ctrl+Space: 続き、Ctrl+Shift+S/Q/E: 要約/質問/編集代行。
結果を確認して挿入または置換を選びます。実行中にプラグインを停止すると、その実行結果は文書に適用されません。
